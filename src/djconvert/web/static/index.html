      Libraries
      
    
      Sync matches tracks between two libraries (by path, then file name and size, then artist, title
      and length), adds what's missing and merges cues, grids, metadata and playlists. Libraries are updated in
      place, with a backup of each file changed. Quit the DJ software first. Rekordbox's own library
      (master.db) can only be a source; sync to Rekordbox through a USB stick or XML.
